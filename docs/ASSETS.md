# Visual asset provenance

- The fifteen cartoon demo covers in public/covers are original, code-authored Setvia UI assets. Regenerate them with node scripts/create-demo-covers.mjs. They are not Meta Muse Image results and imply no live generation.
- The cat mascot and participant avatars are original SVG components in client/Mascot.tsx.
- The UI uses a plain-text hackathon credit. No Meta AI logo or symbol is included; production model inference is not integrated.
- public/github-mark.svg comes from https://raw.githubusercontent.com/primer/octicons/main/icons/mark-github-16.svg. Its upstream MIT license is retained as public/github-mark.LICENSE.
- Lexend is supplied by @fontsource-variable/lexend under OFL-1.1. Lucide interface icons use the package's ISC license.
